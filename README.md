# Star Wars: Global Conflict — 2.0

Новая версия игры. Всё, кроме боёв, перенесено из [sw-rpg](https://github.com/C0BecTb11/sw-rpg) как есть: галактическая карта, экономика, постройки, исследования, найм, герои, аккаунты и прогресс. Новое — бои в реальном времени (абордаж, наземка, космос).

- Сайт: https://c0bectb11.github.io/SW-RPG2.0/
- Старая игра работает параллельно: https://c0bectb11.github.io/sw-rpg/
- База общая — тот же проект Supabase, тот же мир и те же аккаунты.

## Папки

| Папка | Что внутри |
|---|---|
| `index.html`, `auth.html`, `game/`, `js/`, `css/`, `assets/`, `partials/` | сайт игры (перенесён из sw-rpg) |
| `shared/rt-core.js` | общий модуль боя: отряды и одиночки, чанки, поля направлений, двоичный поток. Работает и в браузере, и на сервере |
| `shared/rt-figures.js` | фигурки бойцов (клоны, B1, B2, BX) — набор картинок для отрисовки |
| `server/` | игровой сервер боёв: Node.js без зависимостей, свой WebSocket, журнал в Supabase |
| `server/deploy/` | установка на Hetzner: `cloud-config.yaml` → `install.sh`, автообновление `update.sh` |
| `server/bench/load.js` | нагрузочный замер сервера: `node server/bench/load.js 120 10` |
| `proto/` | прототип боя на ~500 и ~2000 войск с замером плавности: https://c0bectb11.github.io/SW-RPG2.0/proto/ |
| `ships/` | корабли 2.0 снаружи и изнутри: https://c0bectb11.github.io/SW-RPG2.0/ships/ |
| `space/` | прототип космического боя: цель для каждой пушки, щиты по секторам, пожары и экипаж внутри: https://c0bectb11.github.io/SW-RPG2.0/space/ |
| `shared/rt-crew.js` | экипаж корабля: тела без прохода сквозь стены и друг друга, посты, тушение, ремонт, замена погибших |
| `shared/rt-space.js` | расчёт космического боя (браузер и сервер) |
| `shared/ships/*.json`, `shared/rt-ship.js` | планы отсеков кораблей (клетка 2 м) и их чтение |
| `tools/ships/` | сборка планов из спрайта карты и плана по канону: `python3 tools/ships/build.py` |
| `sql/` | данные и миграции базы; `rt_2_0_*.sql` — таблицы сервера боёв и блокировка «бой 2.0 / старая игра» |

## Блокировка между старой игрой и 2.0

Юнит или корабль в бою 2.0 занят для старой игры: любое действие игрока с ним (ход, атака, погрузка, ремонт, передача, абордаж) откатывается с сообщением «… сейчас в бою 2.0», а тики cron его просто пропускают. И наоборот: сервер 2.0 не возьмёт в бой то, что в старой игре в пути, в абордаже, в ремонте, передаётся или стреляло последние 90 с. Если сервер пропал (нет сердцебиения 90 с), блокировка сама снимается.

Перенесено из sw-rpg на коммите `215da6e`.
