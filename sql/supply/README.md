# Снабжение: снимок базы

Функции и таблицы снабжения, логистического хаба, торгового поста, рынка и склада планеты долго жили только в базе.
Здесь снимок на 24.10.2026: тела функций выгружены через `pg_get_functiondef`, каждое сверено с базой по `md5(prosrc)`.
Правки шага 2 (`sql/supply_fixes.sql`), шага 3 (`sql/supply_client.sql`) и шага 4 (`sql/supply_map.sql`, `sql/supply_buildings.sql`) в снимок уже внесены — 91 функция, сверено с базой после применения.
Шаг 5 (уборка): `sql/supply_cleanup.sql` отвязал живые функции от конвоев, `sql/supply_drop_convoys.sql` (вручную, SQL Editor)
удаляет таблицу `convoys` и 9 функций конвоев — в снимке их уже нет.
Выход флота к гиперлинии (`sql/supply_zone.sql`, `sql/supply_zone_live.sql` — и в живой орбите через сервер боя): `supply_fleet_to_zone`, `rt_space_orders_take`, правка `supply_route_step` — 84 функции.
Груз меняют у площадки сброса (`sql/supply_pad.sql`, 27.10.2026): `supply_fleet_to_pad`, `supply_unload_room`, `jettison_commander_cargo`, правки `supply_route_step`, `supply_stop_actions`, `set_supply_route_status`, фаза `returning`.
Тогда же снимок досверен с базой: убраны проверки абордажа и луча, снятые шагом 4б старого кода (`start_commander_move`, `supply_fleet_to_zone`, `transfer_block_ship`),
удалённая `boarding_drop_cargo`; `cancel_market_lot` и `dispatch_market_pickup` — как в базе после #130. 86 функций, md5 всех сверены.

Это **справка о том, что лежит в базе**, а не миграция. Правки снабжения делаются отдельными файлами `sql/supply_*.sql`
и потом переносятся сюда, чтобы снимок оставался верным. План переделки — `claude/supply-plan.md` в проекте.

| Файл | Что внутри |
|---|---|
| `tables.sql` | таблицы, ограничения, индексы, политики RLS, настройки, такты cron |
| `stock.sql` | склад планеты: предел, пополнение, списание, ручная погрузка и выгрузка кораблей |
| `cargo.sql` | груз в трюмах, окончание перелёта командира |
| `paths.sql` | путь через миры своей стороны (`convoy_route`, `convoy_route_to`) — для рейсов и перелётов |
| `market.sql` | рынок: лоты, брони, погрузка, истечение брони, вывоз покупки рейсом |
| `routes.sql` | рейсы снабжения: такт, шаг рейса, действия на остановке, правила складов, чтение для окна |
| `access.sql` | доверие и доступ к складам между игроками |
| `commander_routes.sql` | дальние перелёты командира с автопрыжками |
| `trade_post.sql` | торговый пост: цены и продажа NPC |
| `related.sql` | функции других механик, от которых зависит снабжение: захват, перелёт, перехват, предупреждения |

Сверка: тела функций между `AS $function$` и `$function$` должны давать тот же md5, что `md5(prosrc)` в базе.
